## 多用户运行

- 首次运行：20 个独立地址，43 次兑换、37 次添加、13 次撤回，储备和真实余额一致。原始报告见 `simulation-demo-report.json`；录屏中的数值来自这一轮。
- 在浏览器新增第二个池并烧毁部分 NFT 后再次运行：20 个地址，43 次兑换、37 次添加、12 次撤回，通过。报告见 `simulation-report.json`。
- 重复运行会跳过已烧毁的历史 NFT；余额核对会汇总交易所全部池，而不是只拿第一个池与整个合约余额比较。

## 实际浏览器操作

在本地 Hardhat 链的 31337 网络上，通过 IAB 和 Chrome 实际操作并核对了：

1. 选择不同本地账户并独立领取 ALPHA / BETA。
2. 兑换 10 ALPHA，交易确认后余额和储备更新。
3. 为原有池添加流动性，NFT 出现；销毁后 NFT 消失且资产返回。
4. 使用 `npm run extra-token` 部署第三种 GAMMA，为账户 3 发币；从前端创建 ALPHA/GAMMA 池，注入初始流动性并领取 NFT，再销毁赎回。
5. 在 Qiantang 单边交易，搜索双向报价，并从前端调用原子套利。
6. 第一次前端套利实际获利 31.127561 BETA，哈希 `0xb158773a15ab3803e1bbd3f390cf058940f4752ac7dc6d5cb54e3c01d3de5a93`。
7. 录屏中的第二次前端套利实际获利 29.723512 BETA，哈希 `0x54a2b6ced19b63c244fac64fec91e35063265f05e6b1f2e7a387a4887d3f3397`。

以上利润均扣除 DEX 手续费、未扣除 ETH Gas。前后价格、储备和收益截图位于 `screenshots/`。本地链重启后，这些哈希仅作为该次运行的历史证据。

已检查默认窄屏布局与桌面三栏布局；IAB 截图缩放不理想，仓库最终截图及录屏使用 Chrome 实际页面。
