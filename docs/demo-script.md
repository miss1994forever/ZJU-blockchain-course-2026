# 复现练习流程参考

此文档是录制前的练习顺序；正式提交视频和实际内容索引见 [submission.md](submission.md)。

准备：启动链、部署，运行模拟与套利脚本，打开前端。需要有一个仍持有 NFT 的账户；若想从零演示，可新选一个账户领取测试币。

| 时间       | 页面操作                                             | 讲解要点                                          |
| ---------- | ---------------------------------------------------- | ------------------------------------------------- |
| 0–12 秒    | 选择账户，领取 ALPHA / BETA                          | 两种 ERC20，多账户独立领币，本地链 Chain ID 31337 |
| 12–30 秒   | 在 West Lake 兑换 10 枚，显示交易日志与储备变化      | 恒定乘积、0.30% 手续费、真实交易哈希              |
| 30–50 秒   | 添加流动性，查看新铸 NFT                             | NFT 记录池、份额、投入与时间，展开来源列表        |
| 50–65 秒   | 销毁新 NFT 赎回                                      | 取回按份额分配的当前储备，包含手续费              |
| 65–85 秒   | 展示 20 用户模拟报告；比较两交易所价格               | 脚本随机交易和增撤流动性形成价差                  |
| 85–110 秒  | 搜索并执行套利；无机会时先「在 Qiantang 交易 400 B」 | 同一笔交易完成买卖，展示套利前后价格、储备与利润  |
| 110–120 秒 | 展示套利哈希和测试结果                               | 失败回滚由自动化测试覆盖，说明可复现命令          |

录制时不要展示浏览器个人资料或真实私钥。可只录项目浏览器窗口。视频文件名和邮件主题按课程要求改为本人学号、姓名、作业2。
